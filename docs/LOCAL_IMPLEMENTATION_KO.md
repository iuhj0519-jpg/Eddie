# TradingAgents 로컬 구현 범위

## 목표

미국 주식의 공개 재무자료·가격을 분석하여 출처와 한계를 표시하는 한국어 보고서를 생성한다. 기존 PC의 CPU/RAM과 로컬 Ollama를 사용하며 유료 모델 API, 유료 데이터 API, 클라우드 GPU는 사용하지 않는다. 주문 실행은 포함하지 않는다.

## 로컬 환경

Python 3.12.14, Ollama 0.34.4, qwen3:4b를 사용한다. Core Ultra 7 155H와 약 31.6 GiB RAM에서 CPU 추론을 기준으로 삼는다. 문맥은 8192, 모델 및 동시 추론은 각각 1개로 제한한다. [설치 및 실행 안내](LOCAL_SETUP_KO.md)와 [실제 검증 결과](validation/local-llm-smoke.json)를 참고한다.

현재 제공하는 실행기는 작은 고정 자료로 JSON과 도구 호출을 검증한다. 전체 투자 분석 그래프나 정기 보고서 발행 시스템의 완성을 의미하지 않는다.

## 후속 구현

| 단계 | 구현 내용 | 완료 조건 |
|---|---|---|
| 전체 분석 실행기 | Ollama·loopback endpoint·설치 모델 고정, 클라우드 키 및 추적 제외 | 외부 LLM·유료 데이터 설정을 주입해도 전송 전 거부 |
| 무료 자료 수집 | SEC 공시·재무, yfinance 가격, 캐시 | 제출일·기준시각·단위·통화·원본 주소 보존 |
| 최소 분석 | AAPL 1개, 재무·시장 분석, 토론 1회 | 출처가 있는 한국어 Markdown/JSON 보고서 |
| 공시 본문 | 10-K/10-Q의 위험요인·MD&A 절 추출 | 주장과 원문 근거 연결, 문서의 지시문은 데이터로 취급 |
| 품질 평가 | 고정 자료 반복·장문 검사, 향후 성과 추적 | 계산 오류·자료 누락·예측 성과를 구분 |
| 정기 실행 | 로컬 스케줄러, 중복 방지, 실패 기록 | PC 실행 상태 및 오류를 확인 가능 |

전체 실행기는 환경변수와 설정 파일을 읽은 뒤에도 최종 공급자·주소·모델을 검사해야 한다. 로컬 모델 또는 무료 자료 공급이 실패하면 오류/자료 부족으로 종료하고 다른 유료 공급자로 전환하지 않는다. 현재 검증기의 HTTP 제한은 검증 실행에만 적용된다.

계산은 Python이 담당하고 LLM은 해석과 서술을 담당한다. 재무 결측을 0으로 처리하지 않으며 공시 제출일과 회계기간을 구분한다. 과거 시점에 공개되지 않았던 수치를 백테스트에 사용하지 않는다. SEC 요청에 필요한 연락처는 로컬에서만 설정한다.

보고서에는 자료 마감일, 상승·하락 근거, 판단 기간, 반증 조건, 결측, 출처, 모델·코드 버전을 포함한다. 목표가격은 산식·가정·민감도와 함께 제시한다. 검증되지 않은 모델의 자신감을 상승 확률로 표시하지 않는다.

예측 성과는 사전에 고정한 5/20/60 거래일 등의 기간으로 추적한다. 전략 수익률 평가에는 체결 시점·수수료·슬리피지·배당 및 분할을 포함한다. 작은 모델의 연결 검증과 투자 성과 검증은 별개다.
