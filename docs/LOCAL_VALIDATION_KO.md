## 해석과 한계

실제 TradingAgents의 클라이언트 팩토리와 도구 메시지 왕복이 동작한다. 검증에 사용한 숫자는 고정 예제이며 실제 기업 재무자료가 아니다. 전체 분석 그래프, SEC 수집, 투자 보고서, 예측 성과는 이 검사에서 검증하지 않았다.

최종 도구 응답에는 설명이 길게 생성되고 `</think>` 태그가 남았다. `reasoning_effort=none` 요청만으로 출력 정리가 보장되지는 않는다. 계산 결과 확인은 통과했지만 보고서 발행 전에는 출력 정리와 반복 안정성 검증이 필요하다. 1회 연결 검증 결과로 금융 추론 품질을 판단하지 않는다.

HTTP 허용 목록은 `local_llm_smoke.py`에 적용된다. 원본 프로그램 전체의 유료 API 차단을 의미하지 않는다. 전체 분석용 실행기는 [구현 계획](LOCAL_IMPLEMENTATION_KO.md)의 별도 단계다.
