# 디버깅 결과 001 — 승인 대기

이 폴더는 결과 보관을 위해 예약한 빈 구조다. RTL 디버깅, 합성, 시뮬레이션 또는 Gate 승인이 수행되었다는 의미가 아니다.

원본: `workspace/optimized_accelerator`

| 하위 폴더 | 승인 후 보관할 내용 |
|---|---|
| rtl | 디버깅 결과 RTL |
| tb | 해당 결과를 검증한 테스트벤치 |
| memory | 사용한 메모리 초기화 파일 |
| scripts | 해당 결과의 실행·재현 스크립트 |
| reports | 원본 artifacts/실행 Run 링크, 승인 SPEC/Finding, 소스 hash 및 검증 상태 |

현재 `.gitkeep`은 Git에 빈 디렉터리 구조를 보존하기 위한 파일이다. 코드/검증 결과는 아직 없다.

새 Gate 승인 후 별도 디버깅을 반복하면 `rag_debug_output_002`, `003` 순서로 생성하며 이전 결과를 덮어쓰지 않는다. 이 번호는 analysis/run 번호와 독립적이다.

현재 자동 실행기는 격리 workspace에서 검증하며 이 폴더로 자동 배포하지 않는다. 활성 Agent가 승인된 작업의 결과를 보관할 때 실행 출처와 상태를 함께 기록해야 한다. 이 폴더 자체는 새 자동 실행 target이 아니다.
